# 龙虾人物

RSS and audio hosting for 龙虾人物。

## 节目调性

- **定位**：人物故事播客。每期聚焦一个关键人物的一段代表性阶段，而不是做完整传记。
- **选题**：寻找人物真正改变世界、遭遇冲突或暴露其复杂性的关键时刻。
- **表达**：少煽情，多事实；少神话，多结构。既讲人的选择，也讲时代、制度和环境如何塑造这个人。
- **目标**：通过一个人的具体故事，看懂一个更大的思想、时代或结构问题。

## 内容工作流

选题与文字先在对话中讨论、打磨并定稿；**定稿之前不进入 GitHub 发布流程**。定稿后再生成音频并发布 Podcast，同时同步对应文字版。
